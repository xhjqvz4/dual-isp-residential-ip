## 双ISP、原生 IP、住宅 IP，三个词说的不是一件事

原生 IP 说的是 IP 的注册地和机房物理位置对得上，洛杉矶机房的 IP 在 WHOIS 里国家也是美国。住宅 IP 说的是这个 IP 的 ASN 归属，挂的是 Comcast、AT&T 这类民用宽带运营商，而不是 Linode、Vultr 这种 IDC 运营商。双ISP 再往前一步：同一个 IP 在两家的民用运营商名下都有注册记录。

这里有个被反复搞错的地方：**双ISP 不是给你两个 IP**。它指的是同一个 IP 有两家 ISP 的注册记录。WePC 全部套餐的参数栏都写着 IPv4 × 1，一个套餐一个 IPv4，这一点没有例外。要多 IP 只能另外加购。

三个词之间不是包含关系。一个 IP 可以是原生 IP 但属于 IDC 段，也可以是住宅 IP 但只挂一家运营商。买之前先想清楚自己需要的是哪一个属性，别被套餐标题带着走。

## 商品标题里的“双ISP”，能信几分

WePC 美国组页面顶部写着一句宣传语：“三网回程优化，无需中转，全场双isp ip，TK神器”。往下翻单品，情况就没那么整齐：最便宜的洛杉矶静态家宽那款只标了“静态家宽”，没写双ISP；韩国、英国、日本、马来西亚、西班牙、法国几款标的是“原生家宽IP”，日本和马来西亚又同时写了“双ISP”。同样一台机器，描述口径在不同页面之间并不统一。

这不是 WePC 一家的毛病。另一家 IDC 服务商在自家双ISP DIA 新品的官方 FAQ 里把边界写得很直接：该 IP 标记为 ISP 运营商属性，不等同于家用宽带动态 IP，平台风控由多方因素决定，不承诺百分百规避风控。卖的人自己都承认“ISP 属性 IP”和“真实家宽”之间还有距离，那么“双ISP”这三个字本身就不能当成护身符。

拿到机器之后自己验一遍，比看商品标题可靠。步骤不复杂：

1. 访问 `ipinfo.io` 或 `httpbin.org/ip`，确认出口 IP 是目标国家，不是本地 IP。
2. 打开 `iphey.com` 或 `browserleaks.com/ip`，看 IP 类型是否显示 Residential。
3. 看 ISP / Organization 一栏，是不是 Comcast、AT&T、Spectrum、Cogent、NTT 这类运营商名，而不是 Datacenter、Hosting 字样。
4. 检查 HTTP 头里的 `X-Forwarded-For` 有没有泄露你的真实 IP。
5. 看城市、州和你下单时选的地区是否一致。

五项里第三项最关键。WePC 有“新加坡原生（非家宽）”和“英国原生 IPv4（非家宽）”这类型号，名字里带“原生”但不是家宽段，价格也便宜一截。买的时候看清参数栏写的是“原生家宽”还是“原生”。

## 官网写在角落、但会影响你的六件事

**严禁使用 Shadowsocks 协议。** 美国组页面顶部就写着这一行，搭建要按官方教程走。买了之后才发现协议受限，退款和迁移都是麻烦。

**超流量是限速，不是断网。** 多数型号标“超流量限速 3M”，马来西亚款是 5M。1.5TB 用完不会停机，但 3Mbps 意味着基本只能维持后台操作，推流和传大文件别指望。

**全部套餐只有一个 IPv4。** 需要多 IP 单独加购，别指望双ISP 自带两个。

**主流配置只有 512MB 内存。** 这不是笔误，家宽 VPS 的定位就是轻量。装 Windows 不现实，装面板也要挑精简的。要跑重一点的程序，只能上 AUD$39.90 那款 6G 的。

**“无需中转”只对美国组那几款成立。** 官网宣传语写的是“无需中转”，但同一页和全球节点页里，加拿大、西班牙、法国、马来西亚、巴西、阿联酋、日本基础款都标了“建议中转”甚至“必须加中转才能正常”。韩国款写得最细：电信移动直连，联通绕路，直播建议中转。选非美国节点之前，先确认自己有没有现成的中转。
